# Cyber Sanrakshan

Cyber Sanrakshan is an NLP-based toxicity detection web application developed using Flask and VADER Sentiment Analysis.

## Features

- Detects potentially toxic text
- Classifies user input based on sentiment polarity
- Simple web-based interface
- Built using Python and Flask

## Tech Stack

- Python
- Flask
- NLTK
- VADER Sentiment Analyzer
- HTML/CSS

## How It Works

1. User enters text.
2. Flask processes the request.
3. VADER analyzes sentiment polarity.
4. The system classifies the text and displays the result.

## Future Improvements

- Transformer-based toxicity detection (BERT)
- Improved contextual understanding
- Multi-language support
- Real-time moderation suggestions
